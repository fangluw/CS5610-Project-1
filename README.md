# CS5610-Project-1
CS5610 Project 1 write up 

The most challenging part of this assignment is the crossword. I find HTML and CSS easy to work with. 

I used grid to build the puzzle. I used a div to contain all the individual squares, where the individual squares are also a div. Another option that I considered was using table, but I think using grid is a better choice.

I took accessibility when designing this site. I am particularly proud that every individual square in the puzzle has an aria label so it is easy for users relying on a screen reader. 

Given more time or resources, I would add the functionality where the website can check whether the answer that the user provided to the crossword is correct and give feedback to the user accordingly. 

I spent about 20 hours on this assignment.

I used AI for the color choice and I used https://www.ft.com/content/3ee1b4f5-eca7-4939-847d-ec60bd279603 as the crossword puzzle idea.
